**Goal:** Bank a fraction of a winning trade once it reaches T×ATR of profit, leaving a runner on the unchanged wide stop — research-gated, default off.

**Architecture:** A pure `scaleout_remaining()` returns the fraction of the original position still held given open profit. The engine's `_simulate_stops` (which already tracks per-trade entry/extreme/atr) emits a per-bar `size_mult`; `run()` applies `eff_pos = pos × size_mult` to both pnl and turnover. Live runner scales target lots the same way. Gated; deploy conditional.

**Tech Stack:** Python 3.11, polars, numpy, pytest, `uv run`.

## Global Constraints

- TDD: failing test first. Suite: `uv run pytest`.
- Scale-out is size-based (reduce position), NOT a stop change. Disaster stop untouched. `scaleout_frac <= 0` or `scaleout_trigger <= 0` ⇒ disabled ⇒ byte-identical to today. Default off.
- One shared `scaleout_remaining()` in `src/mt5_trader/stops.py`; engine + runner both call it (parity). `stops.py` imports nothing internal.
- Monotonic per trade (anchored to the favorable extreme; resets on flip/re-entry) — never re-adds size after banking.
- Engine: `pos` is applied OUTSIDE `_simulate_stops` (`pnl = leverage*(pos*ret - cost)`); scale-out returns a `size_mult` array and `run()` uses `eff_pos = pos*size_mult` for pnl AND turnover (so the partial-close cost falls out of `|diff(eff_pos)|`).
- Real broker feed (`build_bars`) for backtests. Phase 2 (Task 4) only after the Task 3 gate + sign-off.

# src/mt5_trader/stops.py
"""Stop/position helpers shared by the backtester and the live runner (parity).
Pure: no MT5, no I/O."""
from __future__ import annotations


def scaleout_remaining(open_profit_atr: float, trigger_T: float, close_frac: float) -> float:
    """Fraction of the original position still held after partial profit-banking:
    1.0 below `trigger_T` ATRs of open profit, `(1 - close_frac)` at/above. Disabled
    (returns 1.0) when `close_frac <= 0` or `trigger_T <= 0`."""
    if close_frac <= 0 or trigger_T <= 0:
        return 1.0
    if open_profit_atr < trigger_T:
        return 1.0
    return 1.0 - close_frac
```

#!/usr/bin/env python
"""RESEARCH: sweep scale-out (trigger T, fraction f) per trend book on the real feed.
Scale-out almost always lowers return (caps the fat tail); keep it only if it raises
Sharpe OR meaningfully cuts maxDD on a plateau, without gutting return.

    uv run scripts/research_scaleout.py
"""
from __future__ import annotations

import yaml

from mt5_trader.backtest.engine import BTConfig, run
from mt5_trader.pipeline.data import bars_per_year, build_bars
from mt5_trader.strategies import REGISTRY
from mt5_trader.strategies.meanrev_pairs import spread_bars

TF_EVERY = {"M1": "1m", "M5": "5m", "M15": "15m", "H1": "1h"}
SL_ATR_MULT, ATR_WINDOW, SLIPPAGE_BPS = 8.0, 60, 0.5
TRIGGERS = [0.0, 1.0, 2.0, 3.0, 4.0]   # 0 = baseline (no scale-out)
FRACS = [0.25, 0.5, 0.75]
TREND_BOOKS = {"donchian", "vwap_trend", "london_orb"}


def book_bars(book: dict):
    every = TF_EVERY[book.get("timeframe", "M1")]
    bars = build_bars(book["symbol"], every).sort("ts")
    if book.get("symbol2"):
        bars = spread_bars(bars, build_bars(book["symbol2"], every).sort("ts"),
                           float(book.get("beta", 1.0)))
    return bars, bars_per_year(every)


def main():
    with open("config/portfolio.yaml") as f:
        books = [b for b in yaml.safe_load(f)["books"] if b["strategy"] in TREND_BOOKS]
    for book in books:
        name = book["strategy"]
        bars, bpy = book_bars(book)
        sig = REGISTRY[name](**(book.get("params", {}) or {})).signal(bars)
        print(f"\n=== {name}@{book['symbol']} {book.get('timeframe','M1')} ===")
        print(f"{'T':>4}{'f':>5}{'return%':>10}{'sharpe':>9}{'maxDD%':>9}{'turnover':>10}")
        for T in TRIGGERS:
            for f in ([0.0] if T == 0 else FRACS):
                cfg = BTConfig(sl_atr_mult=SL_ATR_MULT, atr_window=ATR_WINDOW,
                               slippage_bps=SLIPPAGE_BPS, bars_per_year=bpy,
                               scaleout_trigger=T, scaleout_frac=f)
                m = run(bars, sig, cfg).metrics
                print(f"{T:>4.0f}{f:>5.2f}{m['total_return']*100:>10.2f}"
                      f"{m['sharpe']:>9.2f}{m['max_drawdown']*100:>9.2f}"
                      f"{m['total_turnover']:>10.2f}")


if __name__ == "__main__":
    main()
```

```python
def scaled_target(target_lots: float, trail: tuple | None,
                  trigger_T: float, frac: float) -> float:
    """Reduce target lots by the scale-out fraction given the chandelier trail state
    (side, atr_entry, entry, extreme). No trail / zero ATR -> unchanged."""
    if not trail or trail[1] <= 0:
        return target_lots
    _, atr_entry, entry, extreme = trail
    opa = abs(extreme - entry) / atr_entry
    return target_lots * scaleout_remaining(opa, trigger_T, frac)
```
